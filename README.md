# Sổ Thu Hộ

Sổ ghi thu tiền hàng tuần cho Quỹ Tín Dụng, chữ to cho người lớn tuổi.

- Bấm nút **+ đỏ** để thu 1 tuần (có hỏi lại trước khi ghi).
- Xanh lá: chưa thu tuần này. Trắng: đã thu. Xanh dương: trễ 2 tuần trở lên.
- Dữ liệu lưu trên điện thoại đang dùng. Nhớ dùng mục **Sao lưu dữ liệu** thường xuyên.
